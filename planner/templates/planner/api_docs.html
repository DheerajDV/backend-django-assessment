Make a request. See the result.

Swagger UI sends real requests to this deployment. No sign-in or API key is required. Click Try it out, then Execute to run an endpoint.

  1. Check GET /api/health/ for the Django version and station coverage.
  2. Run POST /api/routes/, then inspect the returned map URL, fuel stops, cost, and request counts.
  3. Repeat the same trip to compare metadata.elapsed_ms and actual external API calls. Paste its id into the retrieval endpoint to read the saved plan.
How to read the cost: starting fuel is already paid for; total_fuel_cost covers additional purchases only. The vehicle gets 10 mpg with a 50-gallon tank. Only stations with sourced coordinates can be considered. Every successful result reports coverage, assumptions, and warnings; it does not guarantee the cheapest journey across every road or station.
